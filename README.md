# Who-is-the-Spy - 谁是卧底

经典游戏谁是卧底，线下聚会首选语言类游戏

## 快速开始

1. 启动服务器：
   ```bash
   python server.py
   ```

2. 访问游戏：
   - 本机：http://127.0.0.1:8000
   - 局域网：http://[你的IP]:8000

## 功能特性

- 🎮 支持 3-15 人同时游戏
- 🎭 可配置卧底数量、空白词数量
- 🤖 AI 生成词语（DeepSeek API）
- 📱 响应式设计，手机电脑都能玩
- ⚡ 实时状态同步，1秒轮询
- 💥 爆词功能增加游戏趣味
